## Welcome 👋

欢迎来到西安交通大学电信学部学生科技协会官方 GitHub 组织！

欢迎浏览我们的项目，通过 Issue 交流想法，或提交 Pull Request 参与贡献。期待与你一起交流技术、探索创意、分享成果。

## 加入我们

欢迎对开发、设计和开源协作感兴趣的同学加入！

1. [提交加入申请](https://github.com/XJTU-STEI/.github/issues/new?title=%E7%94%B3%E8%AF%B7%E5%8A%A0%E5%85%A5%E7%BB%84%E7%BB%87&body=%E8%AF%B7%E7%AE%80%E5%8D%95%E4%BB%8B%E7%BB%8D%E4%B8%80%E4%B8%8B%E8%87%AA%E5%B7%B1%E5%92%8C%E4%BD%A0%E6%84%9F%E5%85%B4%E8%B6%A3%E7%9A%84%E6%96%B9%E5%90%91%E3%80%82)。
2. 管理员审核申请，通过后发送组织邀请。
3. 查看 GitHub 通知或邮箱，接受邀请后即可加入组织。
